# 🔐 Login Form (React + React Hook Form)

## Overview

This project is a production-ready **Login Form** built using:

* React
* React Hook Form
* Yup Validation
* Material UI

It demonstrates best practices for handling forms, validation, API calls, and user experience in modern React applications.

---

## Features

* ✅ Form state management using React Hook Form
* ✅ Schema-based validation using Yup
* ✅ Error handling and display
* ✅ Async form submission with loading state
* ✅ Password visibility toggle 
* ✅ Clean and scalable structure

---

## Tech Stack

* React
* React Hook Form
* Yup
* @hookform/resolvers
* Material UI
